## Build pipeline

- Content is read from files at build time.
- The site is exported to plain HTML with `next build`.
- GitHub Actions uploads the `out` folder to GitHub Pages.

Read the [Next.js static export docs](https://nextjs.org/docs/app/guides/static-exports) for details.
